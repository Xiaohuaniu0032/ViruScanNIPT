# Workflow

## Sample-level phase

`ViruScanNIPT.pl` reads the configuration and FASTQ list, validates the core resources,
and calls `bin/makeSampleShells.pl` using list-form process execution. The output root
contains only sample directories. Each sample directory contains one `<sample>.run.sh`
and all files generated by that sample workflow.

The generated shell runs:

1. BWA MEM alignment to the configured human reference.
2. SAM-to-BAM conversion.
3. BAM sorting and indexing.
4. Extraction of unmapped reads.
5. Conversion of unmapped BAM to FASTA.
6. BLASTN search against the viral nucleotide database.
7. BLAST parsing and filtering by identity, alignment length and e-value.

`bin/parseBlast.pl` writes `<sample>_blast_raw_result.xls` and
`<sample>_blast_out_parsed.txt`. The parsed table contains `sample`, `query`,
`subject`, `identity`, `alignment_length`, `evalue` and `viral_name`.

## Summary phase

`bin/summarizeGroupnameResults.pl` reads one parsed file or recursively discovers
all parsed files under a result directory. It maps `subject` to the curated Groupname
table by accession, normalizing away version suffixes.

The Summary script counts distinct query identifiers per sample and Groupname.
It does not rerun BLAST, alter parsed BLAST records or depend on the old merge and
annotation intermediate files.
